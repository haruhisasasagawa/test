# シンプルリマインダーアプリ

シンプルで使いやすいWebベースのリマインダーアプリケーションです。

## 機能

- ✅ リマインダーの追加・削除
- ✅ 日時指定でリマインダーを設定
- ✅ 設定時刻になったらブラウザ通知
- ✅ ローカルストレージに自動保存
- ✅ 期限切れリマインダーの表示
- ✅ レスポンシブデザイン

## 使い方

1. `index.html` をブラウザで開く
2. タイトルと日時を入力して「追加」ボタンをクリック
3. 設定した時刻になると通知が表示されます
4. 不要なリマインダーは「削除」ボタンで削除できます

## 必要な環境

- モダンなWebブラウザ（Chrome, Firefox, Safari, Edge など）
- 通知機能を使用するには通知の許可が必要です

## Excel生成機能

汎用のExcelファイル生成ページ (`excel.html`) を同梱しています。

- ブラウザ上で表形式にデータを入力
- 行・列の追加／削除
- ファイル名・シート名を指定して本物の `.xlsx` としてダウンロード
- SheetJS を CDN から読み込むため、ビルドやインストールは不要（オフライン利用時はネットワーク接続が必要）

`index.html` 上部のリンクからアクセスできます。

## ファイル構成

```
.
├── index.html    # メインHTML（リマインダー）
├── style.css     # スタイルシート
├── app.js        # リマインダー機能
├── excel.html    # Excel生成ページ
├── excel.js      # Excel生成ロジック（SheetJS利用）
└── README.md     # このファイル
```

## 注意事項

- データはブラウザのローカルストレージに保存されます
- ブラウザのデータを削除するとリマインダーも削除されます
- 通知を受け取るにはブラウザで通知の許可を有効にしてください
