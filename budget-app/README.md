# 月次予算割振アプリ

毎月の人件費予算を「項目別・週別」に割り振る作業を、Excelブック（予算割振ブック）の
計算ロジックそのままにブラウザ上で行うためのアプリです。

主役は **項目別の割振**（障がい者雇用・新規採用研修・既存スタッフ研修・防災訓練・棚卸・
ストア準備／返品・リーダー手当 など）。明細に「どの週に何回実施するか」を入れると、
週別金額・月計・予算比・差額まで自動で出ます。接客部門の割振も別タブに用意しています。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge など）でダブルクリックして開く
   - インストール・ネット接続は不要です。ファイル一式（`index.html` / `style.css` / `app.js`）を
     共有フォルダやUSBに置いてそのまま使えます。
   - **1ファイルで持ち運びたいときは `standalone.html`**（中身は同じ）。
     `index.html` などを修正したら `node build-standalone.js` で再生成します。
2. 画面右上で **年・月** を選ぶ（◀▶ で前月・翌月に移動。開始WEEKは自動計算、必要なら手修正）
3. タブ 1 から順に入力していく

| タブ | 内容 |
|---|---|
| 1. 項目別割振 | **メイン画面**。項目ごとの実施予定と週別金額、予算比・差額 |
| 2. 動員入力 | 日別動員（貼り付け可）。週の区切りと動員構成比を作る |
| 3. 有休・更衣 | 有休計算表と更衣時間 |
| 4. 接客部門 | 接客部門予算の週別・部門別割振、部門構成比 |
| 5. 集計・出力 | 項目別集計、実施予定明細、接客部門集計、チェック、コピー／CSV |
| 6. 設定・データ | 保存・読込・前月複製・JSON入出力、週の区切り一覧 |

## 項目別割振（メイン画面）

各項目のカードは次の構成です。

```
項目名 ｜ 月予算 ｜ 割振方法 ｜ 月計 ｜ 予算比 ｜ 差額 ｜ 予算ゲージ

内容        時給   時間  人数 │ W5  W6  W7  W8  W9 │ 回数計  金額
週2〜3名    1,251  5.5   1    │  1   1   1   1   1 │   5    34,403
週4         1,251  5     4    │      2   2   2   2 │   8   200,160
─────────────────────────────────────────────────
週別金額                      │ 6,881 56,921 ...   │       284,603
```

- **週ごとの回数（日数）** … その週に何回（何日）実施するかを入れます
- **金額 ＝ 時給 × 時間 × 人数 × 回数**
- 「全週」ボタンで全週に1回ずつ、「回数をすべてクリア」で一括クリア
- 「月計を月予算にセット」で、積み上げた金額をそのまま月予算に入れられます

### 割振方法（項目ごとに選択）

| 割振方法 | 内容 | 向いている項目 |
|---|---|---|
| 実施予定から積み上げ（既定） | 上記の回数入力から週別金額を計算 | 障がい者雇用、研修、防災訓練、棚卸、ストア準備・返品 |
| 月予算を動員構成比で配分 | 月予算を週別動員の構成比で按分 | 新規採用研修など、動員に合わせて配分する項目 |
| 月予算を週均等で配分 | 月予算を週数で等分 | 均等に置く項目 |
| 週別に直接入力 | 週ごとに金額を直接入力（補助ボタンあり） | リーダー手当など単発のもの |

按分・端数処理はすべて **最大剰余法** を使うため、週別金額の合計は月予算（または積み上げ額）と
ぴったり一致します。

## 計算ロジック（Excelブックとの対応）

| 項目 | ロジック |
|---|---|
| 週の区切り | **金曜〜木曜**。月初・月末は端数の週（例：2026年4月は W5(4/1〜4/2)、W6(4/3〜4/9)…W9(4/24〜4/30) の5週） |
| WEEK番号 | **3/1 を含む週を第1週**とする年度通し番号。「自動」ボタンで再計算、手修正も可 |
| 週別動員構成比 | 週動員 ÷ 月動員 |
| 項目の金額 | 時給 × 時間 × 人数 × 回数 |
| 有休 | 単価 × 時間 × 人数。予算との差額を各週へ均等配分し、補正後合計が予算と一致する。1日あたり ＝ 補正後 ÷ 人数 |
| 更衣時間 | 単価 × (時間(分) ÷ 60) × 人数。予算 ＝ 予算基準額 × 接客部門の予算比 |
| 接客部門 週予算 | 月間予算 × 週別動員構成比（手入力に切替も可） |
| 接客部門 部門別 | 週予算 × 部門構成比（FLOOR / CONCESSION / STORE / OFFICE）＋ 予算外 |
| 合計行 | Excelと同じく **有給休暇を除いた** 合計 |

## 動員の貼り付け

「2. 動員入力」の貼り付け欄にExcelの動員列をコピーして「取込」を押します。

- **1列形式**：1日から順に1行1日として取り込みます
- **2列形式**：`4/1[TAB]5359` のように日付付きなら、順不同でも日付どおりに入ります

## Excelへ戻す

各表の下のボタンから出力できます。

- **Excel貼付用にコピー** … タブ区切りでクリップボードへ。Excelのセルにそのまま貼り付け
- **CSVダウンロード** … BOM付きUTF-8のCSVで保存（Excelで開いても文字化けしません）

ファイル名は `summary-by-item_2026-04.csv` のように「表の種類＋対象月」です
（日本語のファイル名はブラウザによって欠落するためASCIIにしています）。
claude.ai で公開したページから使う場合、CSVが許可されていない環境では自動的に
タブ区切りの `.txt` で保存されます。

## データの保存

- 入力は自動でブラウザのローカルストレージに**月単位**で保存されます（`保存済み hh:mm` 表示）
- 「6. 設定・データ」から、保存済み月の読込・**前月の複製**（項目・単価・予算を引き継ぎ、動員は空）・
  JSON書出／読込・当月リセットができます
- 別のPCへ移すときは JSON書出 → 移行先で JSON読込

> ブラウザのデータを消去すると保存内容も消えます。重要な月はJSON書出でバックアップしてください。

## Excelブックとの主な違い

- 金額は**円単位**で扱います（Excelは小数を保持するため、1円単位の差が出ることがあります）。
  週別の端数は最大剰余法で処理し、月計は実際の合計と一致します
- 日別動員が未入力の場合、動員構成比による按分は**週均等**にフォールバックします
- Excelの「週」列（＝1週あたりの実施日数）は、本アプリでは週ごとの回数入力に置き換えています
