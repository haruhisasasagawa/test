# 月次予算割振アプリ

劇場の人件費予算を毎月「週別・部門別・項目別」に割り振る作業を、Excelブック
（予算割振ブック）の計算ロジックそのままにブラウザ上で行うためのアプリです。

動員を貼り付けて予算額を入力すれば、週の区切り・WEEK番号・按分計算・端数調整が
すべて自動で行われ、Excelへ貼り戻せる形で出力できます。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge など）でダブルクリックして開く
   - インストール・ネット接続は不要です。ファイル一式（`index.html` / `style.css` / `app.js`）を
     共有フォルダやUSBに置いてそのまま使えます。
2. 画面上部で **対象月** を選ぶ（開始WEEKは自動計算、必要なら手修正）
3. タブ 1 → 6 の順に入力していく

| タブ | 入力する内容 | 自動で出るもの |
|---|---|---|
| 1. 基本設定 | 接客部門の月間予算、部門構成比 | 週数 |
| 2. 動員入力 | 日別動員（貼り付け可） | 曜日・WEEK・週別動員・構成比 |
| 3. 接客部門割振 | 予算外（ミーティング・棚卸・返品など） | 週予算、部門別配分、月計・予算比・差額 |
| 4. 項目別予算 | 各項目の月予算と単価表（時給×時間×週×人数） | 週別配分、月計・予算比・差額 |
| 5. 有休・更衣 | 週別の人数、有休予算 | 金額、差額の均等配分、補正後金額、1日あたり |
| 6. 集計・出力 | － | 項目別集計、接客部門集計、チェック結果、コピー／CSV |

### 動員の貼り付け

「2. 動員入力」の貼り付け欄にExcelの動員列をコピーして「取込」を押します。

- **1列形式**：1日から順に1行1日として取り込みます
- **2列形式**：`4/1[TAB]5359` のように日付付きなら、順不同でも日付どおりに入ります

### Excelへ戻す

「6. 集計・出力」の **Excel貼付用にコピー** を押すとタブ区切りでクリップボードに入るので、
Excelのセルにそのまま貼り付けられます。CSVダウンロードも可能です。

## 計算ロジック（Excelブックとの対応）

| 項目 | ロジック |
|---|---|
| 週の区切り | **金曜〜木曜**。月初・月末は端数の週になる（例：2026年4月は W5(4/1〜4/2)、W6(4/3〜4/9)…W9(4/24〜4/30) の5週） |
| WEEK番号 | **3/1 を含む週を第1週**とする年度通し番号。「自動」ボタンで再計算、手修正も可 |
| 週別動員構成比 | 週動員 ÷ 月動員 |
| 週予算 | 接客部門 月間予算 × 週別動員構成比（合計は必ず月間予算と一致） |
| 部門別配分 | 週予算 × 部門構成比（FLOOR / CONCESSION / STORE / OFFICE） |
| 部門別合計 | 予算配分 ＋ 予算外 |
| 単価表の金額 | 時給 × 時間 × 週 × 人数 |
| 有休 | 単価 × 時間 × 人数。予算との差額を各週へ均等配分し、補正後合計が予算と一致する。1日あたり ＝ 補正後 ÷ 人数 |
| 更衣時間 | 単価 × (時間(分) ÷ 60) × 人数。予算 ＝ 予算基準額 × 接客部門の予算比 |
| 合計行 | Excelと同じく **有給休暇を除いた** 合計 |

### 項目別予算の配分方法

| 配分方法 | 内容 | 主な用途 |
|---|---|---|
| 単価表（毎週同額） | 単価表の1週あたり合計を毎週計上 | 障がい者雇用、ストア準備・返品（予算分） |
| 動員構成比で按分 | 月予算を週別動員構成比で按分 | 新規採用研修（トレーニー／トレーナー） |
| 週均等で按分 | 月予算を週数で等分 | － |
| 手入力 | 週ごとに直接入力（補助ボタンあり） | 既存スタッフ研修、防災訓練、棚卸、リーダー手当 など |

手入力のときは「動員構成比で埋める」「均等で埋める」「1週あたり合計で埋める」
「**単価表の行を週順に割当**」（単価表の1行目→W1、2行目→W2 …）のボタンで一括入力できます。

按分はすべて **最大剰余法** で端数処理するため、週別金額の合計は月予算とぴったり一致します。

## データの保存

- 入力は自動でブラウザのローカルストレージに**月単位**で保存されます（`保存済み hh:mm` 表示）
- 「1. 基本設定」から、保存済み月の読込・**前月の設定を複製**（予算・単価表・構成比を引き継ぎ、動員は空）・
  JSON書出／読込・当月リセットができます
- 別のPCへ移すときは JSON書出 → 移行先で JSON読込

> ブラウザのデータを消去すると保存内容も消えます。重要な月はJSON書出でバックアップしてください。

## Excelブックとの主な違い

- 金額は**円単位で四捨五入**します（Excelは小数を保持するため、1円単位の差が出ることがあります）
- 日別動員が未入力の場合、動員構成比による按分は**週均等**にフォールバックします
- 「週予算を手入力する」にチェックすると、動員構成比によらず週予算を直接入力できます
