# 売店発注ツール

映画館の飲食売店（フード・ドリンク・包材）の発注業務を支援するWebツールです。
来場者予測とPI値から必要数を算出し、勘に頼らない発注を行えます。

`order/index.html` をブラウザで開くだけで動作します（サーバー不要・インストール不要）。

## 発注数の考え方

```
カバー日数   = リードタイム + 発注サイクル
予測消費数   = カバー期間の想定来場者数 × PI値 ÷ 100
安全在庫     = 1日平均来場者数 × PI値 ÷ 100 × 安全在庫日数
不足数       = 予測消費数 + 安全在庫 − 現在庫 − 入荷予定
推奨発注数   = ceil(不足数 ÷ 入数) を発注ロット単位に切り上げ
```

- **PI値**：来場者100人あたりの消費数。ポップコーンなら「100人来場で18個売れる」なら 18。
  包材も同じ考え方で設定します（例：ドリンクカップM = ドリンクM の販売数）。
- **繁忙係数**：大作公開週や連休など、通常より来場が見込める週に 120%・150% と入力すると
  予測消費数と安全在庫が同じ比率で増えます。
- **入荷予定**：発注済かつ未入荷の数量が自動で差し引かれるため、二重発注を防げます。

## 画面

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 欠品リスク・要発注の一覧、直近の発注状況 |
| 発注作成 | 商品別の推奨発注数の算出、発注確定、発注書の印刷・CSV出力 |
| 在庫入力 | 棚卸入力（発注単位＋端数で入力、消費単位へ自動換算） |
| 商品マスタ | 商品の追加・編集・削除、CSVでの一括入出力 |
| 発注履歴 | 発注内容の確認、入荷処理（在庫へ自動加算）、取消、CSV出力 |
| 設定 | 劇場名・担当者・発注サイクル・安全在庫日数・曜日別想定来場者数・バックアップ |

## 基本的な使い方

1. **設定**タブで劇場名・発注サイクル・安全在庫日数・曜日別の想定来場者数を入力する
2. **商品マスタ**タブで自劇場の商品・仕入先・単価・PI値に置き換える（CSV取込も可）
3. **在庫入力**タブで棚卸結果を入力する
4. **発注作成**タブで「推奨数を一括反映」→ 数量を調整 → 「発注を確定する」
5. 仕入先ごとに発注が登録されるので、**発注書を印刷**または**CSV出力**して送付する
6. 納品されたら**発注履歴**タブで「入荷済にする」→ 在庫に自動加算される

## 商品マスタの項目

| 項目 | 説明 |
| --- | --- |
| 商品コード | 社内コード。CSV取込時の突合にも使用 |
| カテゴリ | フード / ドリンク / 包材 |
| 仕入先 | 発注書はこの単位で分割されます |
| 発注単位 | ケース・箱・本など、発注時の単位 |
| 入数 | 発注単位1つあたりの消費単位数（1ケース＝500杯分 なら 500） |
| 単価 | 発注単位あたりの仕入単価（税抜） |
| PI値 | 来場者100人あたりの消費数 |
| リードタイム | 発注から入荷までの日数。納品希望日の算出にも使用 |
| 発注ロット | この倍数に切り上げて発注します |
| 保管場所 | 常温 / 冷蔵 / 冷凍。棚卸時の絞り込みに使用 |

## CSVについて

- 出力はBOM付きUTF-8のため、Excelでそのまま開いても文字化けしません。
- 取込は出力と同じ列構成です。まず「マスタCSV出力」で雛形を取得し、編集して取り込むのが確実です。
- 取込は商品マスタの**全置換**です。在庫と発注履歴は保持されます。

## データの保存について

- データはブラウザの localStorage に保存されます。**端末・ブラウザごとに独立**しています。
- 端末を移行する場合や共有する場合は、設定タブの「全データをJSON出力」／「JSONから復元」を使用してください。
- ブラウザのデータ削除（キャッシュクリア等）で消えるため、定期的なJSONバックアップを推奨します。

## 注意事項

- 初期データの商品名・仕入先・単価・PI値はすべて**サンプル値**です。実運用前に必ず自劇場の値へ置き換えてください。
- 金額はすべて税抜で計算しています。
- 発注書の送信機能はありません。印刷またはCSV出力後、既存の発注フロー（メール・FAX・仕入先システム）でご利用ください。
