# 売店発注ツール（Web版）— ランウェイ・ビュー

映画館の飲食売店（フード・ドリンク・包材）の発注ツールです。
ブラウザだけで動きます（サーバー不要・インストール不要）。

- 開発用: `index.html` をブラウザで開く
- 配布用: `python3 order/build_single.py` で `dist/売店発注ツール.html`（1ファイル）を作る

## 設計の考え方

発注の判断は、実のところ**時間との勝負**です。「在庫があと何日もつか」と
「リードタイムに間に合うか」の比較でしかありません。ところが在庫表は数量を並べるだけなので、
この時間の余裕がまったく見えません。

そこでこのツールは、在庫を**上映スケジュール表（タイムテーブル）の形式**で見せます。
劇場スタッフが毎日見ている情報の形なので、慣れがそのまま使えます。

```
今日 ─────────────────────────────── 14日後
     ████████████│░░░░░░
     └ 在庫がもつ │      └ 発注すると伸びる分
       期間        └ 発注デッドライン
```

| 要素 | 意味 |
| --- | --- |
| バーの長さ | 在庫（＋入荷予定）が尽きるまでの日数 |
| バーの色 | 緑＝余裕／橙＝発注サイクル内に切れる／赤＝今日が発注期限 |
| 縦の線 | 発注デッドライン（＝在庫が尽きる日 − リードタイム） |
| 点線の帯 | いま入力した発注数で在庫がどこまで伸びるか |

赤いバーは「今日発注しないとリードタイム的に間に合わない」商品です。
数量を増やすと点線の帯がその場で伸びるので、**発注の効果をその場で確かめられます**。

画面の一番上には結論だけを大きく置いています。「何品目に発注が必要か」を読めば、
その日の作業量が一目で決まります。

## 画面

| 画面 | 内容 |
| --- | --- |
| タイムテーブル | 発注の判断と数量入力。発注書の印刷・CSV出力・発注確定 |
| 棚卸 | 発注単位＋端数での在庫入力（カテゴリ・保管場所で絞り込み） |
| 商品 | 商品マスタの追加・編集・削除、CSVの入出力 |
| 発注履歴 | 入荷処理（在庫へ自動加算）、取消、CSV出力 |
| 設定 | 劇場名・発注サイクル・安全在庫日数・繁忙係数・曜日別想定来場者数・バックアップ |

## 計算式

```
1日あたり消費数 ＝ 平均想定来場者数 × 繁忙係数 × PI値 ÷ 100
ランウェイ      ＝ (現在庫 ＋ 入荷予定) ÷ 1日あたり消費数
発注デッドライン ＝ ランウェイ − リードタイム
予測消費数      ＝ (リードタイム＋発注サイクル)期間の想定来場者数 × PI値 ÷ 100
安全在庫        ＝ 1日あたり消費数 × 安全在庫日数
推奨発注数      ＝ 予測消費数 ＋ 安全在庫 − 現在庫 − 入荷予定
                  → 入数で割り、発注ロット単位に切り上げ
```

**PI値**は来場者100人あたりの消費数です。ポップコーンMなら「100人来場で12個売れる」なら12。
包材も同じ考え方で設定します。**繁忙係数**は大作公開週に120%・150%と入れると、
予測消費と安全在庫が同じ比率で増えます。

発注済みで未入荷の数量は自動的に差し引かれるため、二重発注を防げます。

## 見た目について

- 配色は題材から取っています。客席の暗がり、スクリーンに落ちる光、ポップコーンのバター色。
  バター色は操作できる要素にだけ使い、状態を表す色とは層を分けています。
- 状態色（余裕／要発注／今日が期限）は明るいテーマと暗いテーマで別の値を持ち、
  それぞれの地の上で色覚特性を含めた識別性を検証しています。
  色だけに頼らないよう、必ずテキストのラベルを併記しています。
- 端末の設定に合わせて明暗が切り替わります。右上のボタンで手動切り替えもできます。
- 数値はすべて等幅で桁が揃います。

## データの保存について

- データはブラウザの localStorage に保存されます。**端末・ブラウザごとに独立**しています。
- 端末を移る場合や共有する場合は、設定画面の「JSONで書き出す」「JSONから戻す」を使ってください。
- ブラウザのデータ削除で消えるため、定期的な書き出しを推奨します。

## 注意事項

- 初期データの商品名・仕入先・単価・PI値は**サンプル値**です。運用前に実際の値へ置き換えてください。
- 金額はすべて税抜です。
- 発注書の送信機能はありません。印刷またはCSV出力後、既存の発注フローでご利用ください。
