# 月次予算割振.xlsx の使い方

その月の**動員予測**をもとに、**金曜〜木曜の週ごとの構成比**で予算を自動的に割り振るExcelです。
**シートを月ごとに複製する必要はありません。**「設定」シートの年・月を変えると、
日付・週の区切り・WEEK番号がすべて入れ替わります。

## シート構成

| シート | 役割 | 入力するところ |
|---|---|---|
| 設定 | 対象月と週の区切り | 年／月／開始WEEK |
| **動員予測** | 日別（または週別）の動員予測 → **週ごとの構成比** | 日別動員予測（D列）／週別に入れる場合はK列 |
| **予算割振** | **月予算を構成比で週へ自動配分** | 各項目の月予算（B列） |
| **接客部門** | **日別の予測動員から部門別の人件費を自動計算** | 早朝・ナイト、追加分、予算動員 |
| 明細 | 週ごとの回数から積み上げたい項目用（任意） | 単価・時間・人数・週ごとの回数 |
| 有休 | 有休計算表 | 単価・時間・予算・週ごとの人数 |
| 人件費マスター | 動員帯別の部門別人件費テーブル | 帯・標準総額・構成比（通常は変更不要） |

入力するのは**黄色いセル（青字）だけ**です。白いセルは数式なので触らないでください。

## 1. 動員予測を入れる

「動員予測」シートのD列に日別の予測を入れると、右の表で**金曜〜木曜の週ごとに合計**され、
その月の何％にあたるか（構成比）が出ます。

| 週 | WEEK | 期間 | 日別からの合計 | 週で直接入力 | 動員予測 | 構成比 |
|---|---|---|---|---|---|---|
| 1 | W5 | 4/1〜4/2 | 8,517 | | 8,517 | 3.80% |
| 2 | W6 | 4/3〜4/9 | 32,853 | | 32,853 | 14.66% |
| 3 | W7 | 4/10〜4/16 | 54,559 | | 54,559 | 24.35% |
| 4 | W8 | 4/17〜4/23 | 58,522 | | 58,522 | 26.12% |
| 5 | W9 | 4/24〜4/30 | 69,608 | | 69,608 | 31.07% |

- 日別の予測がなく**週単位の予測しかない場合は、K列（週で直接入力）に入れてください**。
  K列に数字があればその週はK列の値を使います。
- ここで出た構成比が、そのまま「予算割振」シートの割振に使われます。

## 2. 予算割振（メイン）

各項目の**月予算（B列）を入れるだけ**で、週ごとの構成比に応じて金額が割り振られます。

| 項目 | 月予算 | 割振方法 | W5 | W6 | W7 | W8 | W9 | 配分計 |
|---|---|---|---|---|---|---|---|---|
| 動員構成比 | | | 3.80% | 14.66% | 24.35% | 26.12% | 31.07% | 100% |
| 接客部門 | 22,210,643 | 動員比率 | 844,278 | 3,256,670 | 5,408,354 | 5,801,201 | 6,900,140 | 22,210,643 |
| 新規採用研修（トレーニー） | 392,320 | 動員比率 | 14,913 | 57,525 | 95,531 | 102,470 | 121,881 | 392,320 |
| リーダー手当 | 93,000 | 最終週 | 0 | 0 | 0 | 0 | 93,000 | 93,000 |

### 割振方法（C列・プルダウンで選択）

| 割振方法 | 内容 |
|---|---|
| 動員比率（既定） | その週の動員構成比に応じて配分 |
| **最終週** | **その月の一番最後の週にまとめて計上**（リーダー手当は既定でこれ） |
| 均等 | 週数で等分 |

- 「最終週」は5週の月ならW5、6週の月ならW6と、**その月の最後の週に自動で入ります**
- 1円未満の端数は**最終週で調整**するので、どの方法でも配分計は必ず月予算と一致します
- **明細合計（J列）** … 「明細」シートで積み上げた金額（参考）。**差（K列）** で予算との開きが見えます
- 有給休暇の行だけは「有休」シートの金額をそのまま使います
- 項目は書き換え・追加できます（27行目まで）

### チェック欄（表の下）

| チェック | 意味 |
|---|---|
| 配分計 − 月予算 | 0 なら割り振った金額の合計が月予算とぴったり一致 |
| 差（項目名が一致していない額） | 0 以外なら、明細シートの項目名が予算割振シートと違っています |

## 3. 明細（任意）

研修や防災訓練のように「どの週に何回やるか」で積み上げたい項目に使います。
**金額 ＝ 単価 × 時間 × 人数 × 回数**。使わない場合は空のままで構いません。

| 項目 | 内容 | 単価 | 時間 | 人数 | W5 | W6 | W7 | W8 | W9 | 回数計 | 金額計 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 障がい者雇用 | 駒澤さん | 1,236 | 5 | 1 | 2 | 3 | 3 | 3 | 3 | 14 | 86,520 |

定額のもの（リーダー手当など）は、金額を単価欄に入れて時間・人数・回数を1にしてください。

## 4. 接客部門（現行の割振表と同じ計算）

いま使っている接客部門の割振表と同じ仕組みです。**日別の予測動員がどの動員帯に入るか**で、
部門別（ボックス／コンセ／フロア／ストア／オフィス）の人件費が自動で決まります。

| 日付 | 曜日 | 週 | 予測動員 | ボックス | コンセ | フロア | ストア | オフィス | 早朝 | ナイト… | 日計 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 4/1 | 水 | 1 | 6,562 | 30,650 | 330,420 | 218,612 | 49,102 | 29,711 | | | 658,495 |

- 予測動員は「動員予測」シートのD列を自動で参照します（二重入力は不要）
- 部門別の金額は「人件費マスター」シートの動員帯テーブルから VLOOKUP で引いています
- **早朝・ナイト**（ボックス／コンセ／フロア／ストア）は金額を直接入力します。
  劇場マスター額は「人件費マスター」シートの上部にあります
- 週別集計では、**早朝はフロアに**、ナイト分は各部門に足します（現行の割振表と同じ扱い）
- 週・部門ごとの**追加分**を入力でき、その下に合計・予算配分との差額・予算比が出ます

### 人件費マスター（動員帯別）

| 動員 下限 | 動員 上限 | 標準総額 | 構成比（5部門） | 金額（5部門） |
|---|---|---|---|---|
| 1 | 50 | 97,615 | 2.88% / 42.45% / 46.94% / 2.88% / 4.49% | 2,815 / 41,439 / 45,818 / 2,815 / 4,379 |
| 101 | 200 | 115,506 | … | … |

現行の割振表の32帯をそのまま初期値にしています。金額 ＝ 標準総額 × 構成比。
単価や構成比を見直したときは、このシートを書き換えれば全シートに反映されます。

## 週の区切りとWEEK番号

- 週は **金曜〜木曜**。月初・月末は端数の週になります
  （例：2026年4月 → W5(4/1〜4/2)、W6(4/3〜4/9)、W7、W8、W9(4/24〜4/30) の5週）
- WEEK番号は **3/1を含む週を第1週** とする年度通し番号で自動計算します。
  運用と番号がずれる月は、設定シートのB7を直接書き換えてください（以降の週は連番で追従します）
- 6週になる月（例：2026年1月＝W44〜W49）も自動で6週に分かれます。
  5週の月はW6の列が空欄になり、計算からも自動的に外れます

## 毎月の手順

1. 「設定」シートの**月**を変える（年またぎのときは年も）
2. 開始WEEKが運用と合っているか確認（違えばB7を上書き）
3. 「動員予測」シートに今月の動員予測を入れる
4. 「予算割振」シートに各項目の月予算を入れる → 週別金額が自動で出る
5. 必要なら「明細」で積み上げ、「接客部門」で部門別に分ける

翌月分を残す場合は、**ファイルを「月次予算割振_2026-05.xlsx」のように名前を付けて保存**してから月を変えてください。
