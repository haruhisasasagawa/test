# 月次予算割振.xlsx の使い方

毎月の予算割振を1つのブックで回すためのExcelです。**シートを月ごとに複製する必要はありません。**
「設定」シートの年・月を変えると、日付・曜日・週の区切り・WEEK番号がすべて入れ替わります。

## 入力するところ

**黄色いセル（青字）だけ入力します。** 白いセルは数式なので触らないでください。

| シート | 入力するもの |
|---|---|
| 設定 | 年・月／開始WEEK（自動値が入るが上書き可）／部門構成比 |
| 動員 | 日別動員（D列） |
| **割振** | **項目・内容・単価・時間・人数と、週ごとの回数** ← メインの作業 |
| 集計 | 項目ごとの月予算（I列） |
| 接客部門 | 月間予算／予算外（部門・週ごと） |
| 有休・更衣 | 有休単価・時間・予算／週ごとの人数、更衣の単価・分・人数 |

## 割振シート（メインの作業）

1行が1つの明細です。**週ごとの回数（F〜K列）** に「その週に何回・何日実施するか」を入れます。

| 項目 | 内容 | 単価 | 時間 | 人数 | W5 | W6 | W7 | W8 | W9 | 回数計 | 金額計 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 障がい者雇用 | 駒澤さん | 1,236 | 5 | 1 | 2 | 3 | 3 | 3 | 3 | 14 | 86,520 |
| 既存スタッフ研修 | 週1 | 1,251 | 1 | 1 | 1 | | | | | 1 | 1,251 |

- **金額 ＝ 単価 × 時間 × 人数 × 回数**
- N〜S列に週別金額が自動で出ます（コピペ不要）
- 行は下に自由に追加できます（104行目まで数式が入っています）
- リーダー手当のような定額のものは、**金額を単価欄に入れ、時間・人数・回数を1**にしてください

> 項目名は「集計」シートの項目名と同じ文字にしてください。違う名前の行は集計に載りません。
> 集計シートの下に「集計に載っていない金額」というチェック欄があり、0以外なら不一致があります。

## 集計シート

割振シートの明細を項目ごとに合計し、**予算比・差額**を出します。入力するのは予算（I列）だけです。
有給休暇と更衣時間は「有休・更衣」シートから自動で入ります。

## 週の区切りとWEEK番号

- 週は **金曜〜木曜**。月初・月末は端数の週になります
  （例：2026年4月 → W5(4/1〜4/2)、W6(4/3〜4/9)、W7、W8、W9(4/24〜4/30) の5週）
- WEEK番号は **3/1を含む週を第1週** とする年度通し番号で自動計算します。
  運用と番号がずれる月は、設定シートのB7を直接書き換えてください（以降の週は連番で追従します）
- 週が5週の月はW6の列が空欄になり、金額の計算からも自動的に外れます

## 毎月の手順

1. 「設定」シートの **月** を変える（年またぎのときは年も）
2. 開始WEEKが運用と合っているか確認（違えばB7を上書き）
3. 「動員」シートに日別動員を貼り付け
4. 「割振」シートの回数を今月の予定に更新（単価・時間・人数は前月のまま使えます）
5. 「集計」シートで予算比・差額を確認

翌月分を残したい場合は、**ファイルを「月次予算割振_2026-05.xlsx」のように名前を付けて保存**してから月を変えてください。
